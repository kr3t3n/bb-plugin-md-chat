Open Markdown files in a view where you can send selected text to the thread chat or to a side chat.

## What you get

- A "Markdown with chat" file opener for `.md`, `.markdown` and `.mdx` files.
- A selection menu with **Add to chat** and **Reply in side chat**.
- A **BB preview** button for bb's own preview.

## How it works

The plugin reads the file through bb's file API and draws it with bb's Markdown component. It checks the file for changes every four seconds while the window is visible. Side chats come from the built-in side-chat plugin.
